# 🐍 Modul Praktik Pemrograman Python (TKJ & Cloud)

Panduan belajar Python dari dasar hingga tingkat lanjut yang disesuaikan dengan studi kasus Teknik Komputer dan Jaringan (TKJ) serta Cloud Computing.

---

## 📂 Daftar Modul

| No | File Materi | Topik Pembahasan |
| :--- | :--- | :--- |
| **01** | [`01_basic.py`](01_basic.py) | Variabel, Tipe Data, Konversi Data, Operator, Input/Output |
| **02** | [`02_if_else.py`](02_if_else.py) | Percabangan (`if`, `elif`, `else`), Operator Logika, Studi Kasus Status Port/IP |
| **03** | [`03_for_loop.py`](03_for_loop.py) | Perulangan `for` (`range()`, string), `while loop`, kontrol `break` dan `continue` |
| **04** | [`04_list.py`](04_list.py) | Manipulasi List (Index, Slice, Append, Insert, Pop, Sort, Looping List) |
| **05** | [`05_dictionary.py`](05_dictionary.py) | Key-Value Pair, Method Dict (`keys()`, `values()`, `items()`, `get()`, `update()`) |
| **06** | [`06_nested_list_dict.py`](06_nested_list_dict.py) | Struktur Data Bersarang: List of Dictionaries & Dict with Lists |
| **07** | [`07_advanced.py`](07_advanced.py) | Penggabungan List, Dict, Nested Structure, Loops & Conditional Logic (Studi Kasus Monitoring Server & Jaringan) |

---

## 🚀 Cara Menjalankan Materi

Buka terminal dan jalankan file python yang ingin dipelajari:

```bash
# Jalankan modul tertentu
python3 01_basic.py
python3 02_if_else.py
python3 03_for_loop.py
python3 04_list.py
python3 05_dictionary.py
python3 06_nested_list_dict.py
python3 07_advanced.py
```
